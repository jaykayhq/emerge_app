Several docs embed concrete commands that must be run from the project root: `dart run build_runner build --delete-conflicting-outputs` for code generation, `flutter analyze` for linting, `flutter test` for tests, and `flutter pub get` after asset changes. Asset scaffolding uses PowerShell one-liners to create placeholder PNGs and directories under `assets/images/avatars/`. Pitch deck generation is driven by `create_pitch_deck.py`.
