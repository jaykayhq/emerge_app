Run `flutter pub get` then `dart run build_runner build --delete-conflicting-outputs` to generate Riverpod/Drift code. Start local dev with the Firebase emulators defined in `firebase.json` (Auth :9099, Functions :5001, Firestore :8080, Hosting :5000, UI :4000, Storage :9199). Deploy functions via `cd functions && npm install && firebase deploy --only functions`. Environment variables (`REVENUECAT_WEBHOOK_SECRET`, `INSIGHT_CACHE_DURATION_MS`, `GROQ_API_KEY`) are managed through Firebase Secret Manager and `.env.example`.
