Python 3 scripts using only stdlib (`json`, `argparse`, `pathlib`, `hashlib`, `re`, `collections`) plus Pillow + numpy for image manipulation. Dart scripts use `dart:io` and `package:http` against the Pollinations.ai REST API. Node scripts use `firebase-admin` SDK for Firestore/Auth operations. No package managers or build manifests — every file is run directly via `python`, `dart run`, or `node`.
