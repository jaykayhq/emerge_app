Each script is self-bootstrapping with its own CLI args documented in docstrings/comments. Key workflows: `cd scripts/dataset_distillation && python build_seeds.py && python validate.py && python convert.py --to openai --to gemini --to alpaca`; `GOOGLE_APPLICATION_CREDENTIALS=path/to/serviceAccount.json node scripts/seed_onboarding_catalog.js`; `USE_EMULATOR=true dart run scripts/test_firebase_connection.dart`; `POLLINATIONS_API_KEY=sk_xxx dart run tools/generate_complete_avatars.dart --target=all`.
