Three top-level directories with no shared library — each script is self-contained and invoked directly:
- `scripts/dataset_distillation/` is a cohesive pipeline: `SYSTEM_PROMPT.md` is the single source of truth; `build_seeds.py` emits `seeds.jsonl` (ShareGPT-style JSONL); `validate.py` enforces schema/order/balance/near-duplicate checks; `convert.py` transforms to OpenAI/Gemini/Alpaca formats under `dist/`; `stats.py` reports per-category counts and token estimates; `build_context.py` regenerates agent-context files (`CLAUDE.md`, `.cursorrules`, `.windsurfrules`, `AGENTS.md`, `.github/copilot-instructions.md`) from the same prompt.
- Top-level `scripts/*.dart` / `*.js` / `*.py` are independent one-shot utilities: Firebase Admin SDK data seeders/cleaners (`seed_onboarding_catalog.js`, `purge_orphaned_data.js`), connectivity probes (`test_firebase_connection.dart`, `test_firebase_emulator.dart`), image processing (`remove_splash_bg.py`, `preview_on_dark.py`), and branding generators (`generate_emergearc_branding.dart`).
- `tools/` holds three standalone Dart/Node generators that call the Pollinations.ai image API (`generate_app_icon.dart`, `generate_complete_avatars.dart`, `serve_web.js`).
- `scratch/` is an unstructured dump of ad-hoc experiments (search snippets, decoded maps, test output logs) with no build or import relationships.
