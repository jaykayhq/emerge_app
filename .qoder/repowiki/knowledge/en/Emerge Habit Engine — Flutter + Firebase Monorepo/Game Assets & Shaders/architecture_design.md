Pure data directory with no executable code — assets are organized by media type under `assets/` (`icons/`, `images/`, `rive/`, `sounds/`, `videos/`, `worlds/`) and GPU shaders under `shaders/`. Image assets follow a strict naming convention: archetype portraits live in `images/avatars/` (e.g. `athlete_silhouette.png`), per-archetype level thumbnails are grouped under `images/levels/<archetype>/` with `<prefix>_<chapter>_<level>.png` naming (ath_, cre_, exp_, sch_, sto_, zeal_), and world-level thumbnails reside under `assets/worlds/<trait>/level_N.jpg`. The `shaders/cracked_orb.frag` is a Flutter RuntimeEffect GLSL fragment shader that receives uniforms via index (resolution, time, pan, health_pct) from a Dart painter to render a rotating, health-colored planet disc with noise-based continents and rim glow. Placeholder `.md` files document expected Rive animations rather than shipping binary assets.
