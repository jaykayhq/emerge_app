Firebase options are generated by FlutterFire CLI into `lib/firebase_options.dart` per platform. Seed data is handled server-side via Firebase Admin SDK (`functions/src/seed.ts`) — run `cd functions && npm run seed`. Web builds require `drift_worker.dart.js` and `sqlite3.wasm` served alongside the app. Android signing uses `emerge-release.jks` / `upload-keystore.jks` referenced from Gradle properties. Environment variables are loaded via `flutter_dotenv` on mobile (skipped on web) and compile-time flags via `--dart-define` (e.g. `FLUTTER_ENV`, `SENTRY_DSN`).
