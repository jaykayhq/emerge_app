Each feature screen is a self-contained directory under `stitch_welcome_to_emerge/` (e.g. `login_page/`, `sign_up_page/`, `avatar_system/`, `dashboard__timeline_of_cues/`) containing two files: `code.html` (the full standalone HTML page) and `screen.png` (a visual reference screenshot). There is no shared codebase or build system — every page is an independent, self-sufficient HTML document that inlines its Tailwind CSS configuration via a `<script id="tailwind-config">` block and loads Tailwind from the CDN at runtime. Pages are organized by user journey stage: entry/onboarding (`welcome_to_emerge`, `select_your_archetype`, `map_identity_attributes`), authentication (`login_page`, `sign_up_page`), core habit setup (`build_your_habit_stacks`, `configure_habit_anchors`, `temptation_bundling_interface`), gamification (`avatar_system`, `xp_&_leveling_system`, `cinematic_progress_recaps`), social/community (`creator_blueprints*`, `community_challenges_&_rewards_*`, `tribes_community`), and settings (`app_settings`, `notification_customization`). Dependency direction is one-way: each page is isolated with no cross-file imports, making them suitable for review, presentation, or direct browser preview without a server.
