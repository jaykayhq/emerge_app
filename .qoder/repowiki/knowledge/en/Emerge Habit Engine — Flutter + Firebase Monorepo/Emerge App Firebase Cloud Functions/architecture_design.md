All functions are TypeScript source files under `src/` compiled to `lib/` via `tsc`, with `src/index.ts` as the single entry point that initializes the Firebase Admin SDK once and registers every function using `onCall`, `onSchedule`, or Firestore triggers from `firebase-functions/v2`. Each functional area lives in its own module (`accountDeletion`, `challenges`, `habit_notifications`, `ai_recap`, `revenuecat_events`, `rateLimiter`, etc.) and is re-exported through `index.ts`, so deployment exposes one function per file. Shared infrastructure — the Firestore `db` instance, global options (`maxInstances: 5`, region `us-central1`, 256MiB memory), and secrets like `GROQ_API_KEY` — is centralized in the entry point. Tests mirror the source layout under `test/` and `lib/tests/`, and coverage is generated via Jest with lcov output consumed by the `coverage/` directory.
