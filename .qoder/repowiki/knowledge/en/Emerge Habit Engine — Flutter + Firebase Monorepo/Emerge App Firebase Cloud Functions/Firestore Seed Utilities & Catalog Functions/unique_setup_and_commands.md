`seed.ts` is run as a one-shot script via `npm run seed` after setting `GOOGLE_APPLICATION_CREDENTIALS` or running `gcloud auth application-default login`. The two Cloud Functions are invoked through `firebase functions:shell` or by POSTing to their deployed URLs with an `Authorization: Bearer $ADMIN_SECRET` header; `seed_templates.ts` additionally enforces per-IP rate limiting (10 requests per minute).
